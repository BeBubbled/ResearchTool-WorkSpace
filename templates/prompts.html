    03 / 连接 CHATGPT

    浏览器连接

    检测扩展中…

    首次使用时，在打开本工作台的 Chrome 或 Edge 中加载一次配套扩展。扩展沿用该浏览器的 ChatGPT 登录状态。

    安装 / 更新 / 排查连接
    1. 下载配套扩展 ZIP，解压到固定文件夹。
    2. 在地址栏输入 chrome://extensions 或 edge://extensions，开启“开发者模式”。
    3. 首次安装时，点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。更新时将文件覆盖到原目录，再点击扩展卡片上的“重新加载”。
    4. 刷新此页，并在同一浏览器中登录 ChatGPT。安装或重新加载扩展前已打开的工作台，也需要刷新一次。

    工作台地址需为 http://127.0.0.1:端口/prompts 或 http://localhost:端口/prompts。在扩展“详细信息”中确认允许访问此站点；Codex 内置浏览器无法使用装在 Chrome 或 Edge 中的扩展。

    仅在点击提交时传递本次文字和附件。附件选择不会跨刷新保存；临时传输文件会在成功交接后清理，未完成的文件一小时后在下次访问时清理。
